# Touhou Little Maid: Mahjong

Touhou Little Maid のメイドが Riichi Mahjong の Bot 席で対局するための連携 Mod です。

## 対応環境

クライアントとサーバーの両方へ、本 Mod と次の依存 Mod を導入してください。依存 Mod は、使用する Minecraft と Mod ローダーに対応したものを選んでください。

| 項目 | Forge 版 | NeoForge 版 |
| --- | --- | --- |
| Minecraft | 1.20.1 | 1.21.1 |
| Mod ローダー | Forge 47.4.x 以上 | NeoForge 21.1.219 以上 |
| Java | 17 | 21 |
| [Touhou Little Maid](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid) | 1.5.3 以上 | 1.5.3 以上 |
| [Riichi Mahjong](https://www.curseforge.com/minecraft/mc-mods/riichi-mahjong) | 0.2.0 以上 | 0.4.1 以上 |

## 遊び方

1. メイドを雇用し、タスク画面で **麻雀** を選択します。
2. 麻雀卓の中心から半径 **8 ブロック以内** にメイドを連れてきます。
3. 卓の周囲にメイドが座れる、平らで障害物のない場所を用意します。座席は卓の中心から約 2.1 ブロックです。
4. プレイヤーが希望する席に着席し、通常どおり対局を開始します。卓の席への着席はスニーク＋右クリック、開始は卓中央へのスニーク＋右クリックです。
5. 開始時に近いメイドから Bot 席へ割り当てられ、卓に向かって座ります。打牌・鳴きなどの判断と待ち時間は Riichi Mahjong の既存 Bot が担当します。

| 4人卓のプレイヤー数 | メイドの最大参加数 |
| --- | --- |
| 1 | 3 |
| 2 | 2 |
| 3 | 1 |
| 4 | 0 |

メイドが足りない席は通常の Bot が担当します。閉じた席には割り当てません。対局開始後の追加参加はありません。お座りを指示されている・睡眠中・騎乗中・リードにつながれたメイドは対象外です。メイドの所有者が着席していることは参加条件ではありません。

## 対局終了と好感度

好感度は1局ごとではなく、東風戦・半荘などの**対局全体が完了した時**に変化します。各局の結果表示後は元 Mod の操作で次局へ進めてください。

- 完走したメイド：好感度 **+2**。同じ報酬のクールダウンは 24,000 tick（通常20分）。
- 所有者も参加し、その最終点数がメイドを上回った場合：さらに **+4**。この報酬のクールダウンは 18,000 tick（通常15分）。
- 既存のチェスなどと同様、メイドの敗北による減点はありません。上限・クールダウン・ハート演出は Touhou Little Maid の仕組みを使います。

中断や卓の破壊、タスク変更、死亡、座席からの移動では、そのメイドを解放して通常の Bot に戻し、完走報酬は与えません。保存・再読み込みでは同じ卓とメイドの割当を復元します。卓を別の位置へ移したり、記録を複製したりして元のメイドを奪うことはありません。

## ビルド

`main` は共通ドキュメントと管理設定用のブランチです。ビルドする版のブランチへ切り替え、対応する Java を用意してください。

| 対応版 | ブランチ | 生成ファイル |
| --- | --- | --- |
| Forge 1.20.1 | `mc/1.20.1` | `touhou_little_maid_mahjong-1.20.1-forge-1.0.0.jar` |
| NeoForge 1.21.1 | `mc/1.21.1` | `touhou_little_maid_mahjong-1.21.1-neoforge-1.0.0.jar` |

対象ブランチで以下を実行します。

```powershell
./gradlew.bat build
```

生成先：`build/libs/`
